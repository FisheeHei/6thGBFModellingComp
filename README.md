## 问题概述

论文围绕稳定币在全球金融体系中的竞争格局、储备资产安全性、需求演化趋势及货币主权影响展开建模分析：

- 问题 1：构建多维评价模型，对 USDT 与 USDC 的应用场景、市场竞争力、潜在风险和发展潜力进行定量比较。
- 问题 2：针对法币抵押型稳定币的储备资产配置，在流动性约束下平衡收益性与赎回安全性。
- 问题 3：结合跨境支付、贸易结算、监管政策与市场因素，预测未来五年美元挂钩与非美元挂钩稳定币的增长趋势。
- 问题 4：分析稳定币普及对美元国际地位和经济薄弱国家货币主权的影响，识别潜在高风险经济体。
- 问题 5：基于前述结果，讨论稳定币在粤港澳大湾区、“一带一路”区域合作和 RWA token 化中的应用价值、风险与监管建议。
